These Markdown files are copies of the tasklists, preparation plans and paper-edit
notes maintained in the thesis workspace's separate `Documents` folder. They were
copied here for the `samir` branch handoff on 28 October 2026 so collaborators can
review the implementation progress together with the code.

The workspace `Documents` copies remain the current working trackers. Refresh
these snapshots when sharing later changes. Completed software subtasks do not
establish hardware readiness; follow each file's outstanding verification gates.

Manuscript PDFs, raw field logs, firmware binaries and local credentials are not
included in this snapshot folder. Chapter 4 replacement text is provided as
Markdown; the user reported pasting it into the editable manuscript.
